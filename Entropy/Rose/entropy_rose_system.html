System Architecture

The Entropy Rose system implements a deterministic O(1) quote storage engine based on millisecond-precision hex timestamps. Each quote receives a unique 16-character hex ID derived from YYYYMMDDHHmmssfff timestamp format.

Refined Metadata Schema

As directed by the Manager, the system implements a streamlined metadata structure:

{
  "id": "0047FB356CE62F42",
  "index": 1,
  "date": "2026-09-30",
  "source_speaker": ["hexIDs"],          // List of author hex IDs
  "preference": ["hexIDs"],              // One-directional response tracking
  "backlink": ["url_link"],              // List of URL links
  "tags": {},                            // Empty for now (Manager's strict domain)
  "main_content": "Quote text...",
  "context": "Situational context..."
}

Key Design Decisions:

  • preference field: One-directional list of quote hex IDs that "talk back about" this quote (no reciprocal linking required)
  • source_speaker: Simplified to list of author hex IDs as per Manager's vision
  • tags field: Reserved as Manager's strict domain—no AI suggestions or alterations
  • backlink: Currently placeholder, awaiting Manager's next directive

SQLite Persistence

Golden-standard SQLite engine with WAL mode, FTS5 search, and transactional integrity:

# Deterministic schema migration
def init_db():
    with conn.execute("BEGIN IMMEDIATE;"):
        conn.execute("""
            CREATE TABLE IF NOT EXISTS quotes (
                id TEXT PRIMARY KEY,      -- 16-char hex timestamp
                idx INTEGER UNIQUE NOT NULL,
                main_content TEXT NOT NULL,
                context TEXT,
                date TEXT NOT NULL,
                preference_json TEXT      -- One-directional responses
            );
        """)
        # FTS5 virtual table for search
        conn.execute("""
            CREATE VIRTUAL TABLE IF NOT EXISTS
            quotes_fts USING fts5(...)
        """)
