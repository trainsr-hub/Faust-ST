# Stratum II Observability Canvas (Historical Archive)

*Note: The standalone `faust-c2/` repository directory was retired and safely purged on Sep 7, 2026 following consolidation into sovereign plugins (`faust_plugins/`) and Universe 25. This record is preserved for architectural reference.*

Historical specification for a read-only, non-interactive visual telemetry application formerly hosted in `faust-c2/`, designed to provide observability over multi-agent workflows and command-and-control pipelines.

**Domain Isolation Mandate:**
`universe-25/` remains reserved exclusively for games and entertainment applications (Hub, Golden Hour, Farm Alpha, Farm Beta, Vinyl Angel, Artifact Codex).

**Key Architectural Concepts Preserved:**
1. **Visual DAG Canvas Model**: Cubic Bezier conduit connections with animated flow particles across Strata.
2. **Node Telemetry Card**: Status indicators (ACTIVE, PROCESSING, SYNCHRONIZED, VERIFIED, IDLE), latency, token metrics, and mounted ECS tags.
3. **Cortex ECS Matrix**: Visual indexing of atomic memory components (`core:*`, `rule:*`, `div:*`, `ref:*`) mapped to agent entities.
4. **Three-Tier Warfare Spec**: Visual guide to the Three-Tier Warfare command doctrine and Sovereign Confirmation Gate.
