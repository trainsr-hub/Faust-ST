# Faust Persona Archive (Dormancy Vault)

This directory stores historical, specialized, or retired Faust agent personas in accordance with the **Adaptive Hivemind Lifecycle (Archival Phase)**.

### Archive Protocol:
1. **Preserve Lineage**: When an agent is superseded, specialized, or completed, move its `.md` definition here instead of deleting it.
2. **Reactivation**: If a project requires an archived persona (e.g. specialized data migrators, game jam sprinters, lore historians), it can be moved back to `.claude/agents/` instantly.
3. **Record Metadata**: Ensure archived personas note which project milestone or mission spawned and retired them.
